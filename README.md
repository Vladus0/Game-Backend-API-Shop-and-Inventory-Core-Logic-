# Game Backend API (Shop and Inventory Core Logic)

Асинхронный бэкенд-сервис для обработки внутриигрового магазина и инвентаря

## 🎯 Особенности проекта и архитектура
Проект спроектирован по принципам **Clean Architecture** (Чистая архитектура). Бизнес-логика проведения транзакций полностью изолирована от инфраструктурного слоя

В репозитории представлены два слоя работы с данными:
1. **Локальный слой (Текущий runtime в `main.py`):** Использует легковесное постоянное хранилище на базе JSON-файла (`database.json`). Это позволяет полностью изолировать логику приложения от сетевого окружения ОС и проводить сквозное тестирование транзакций, симулируя поведение реального игрока без поднятия тяжелых сетевых портов
2. **Продакшн слой (Файл `models.py`):** Подготовлены ORM-модели (SQLAlchemy) для перехода на реляционную СУБД **PostgreSQL** со связью таблиц для эффективного масштабирования инвентаря игроков под высокие нагрузки

## 🛡️ Реализованная бизнес-логика:
* **Валидация запросов:** Разбор входящих игровых JSON-пакетов
* **Защита от читерства (Anti-cheat):** Серверная валидация баланса золота игрока перед совершением покупки. Клиент игры не может нарисовать себе предметы локально
* **Атомарность транзакции:** Одновременное списание средств и обновление инвентаря в БД с сохранением состояния при перезапуске сервера

## 🚀 Как запустить симуляцию:
Проект написан на стандартных библиотеках Python и не требует сторонних зависимостей. Гарантирован запуск на любой ОС (включая новейшие версии Python 3.14+)

Выполните команду в терминале:
```bash
python main.py
```

После запуска скрипт автоматически проведет 3 последовательных теста: успешную покупку, повторную покупку с обновлением количества предметов и тест защиты от читеров при нулевом балансе, после чего обновит файл `database.json`
